#  🐻Urso Matemático - Projetos Interativos em Scratch
# Repositório dedicado a projetos interativos focados em **lógica de programação** e **resolução de problemas matemáticos**, desenvolvidos no scratch e exportados para a Web.
-----
## 🎮 Projetos Disponíveis
#### 1. Desfio da Tabuada('desafio_tabuada.html')
* **descrição:** O Urso faz perguntas interativas sobre tabuada e múltiplos para o usuário testarseus conhecimentos.
*  **conceitos de programação:**
*  Laços de Repetição (*Loops*)
*  Variáveis para pontuação/respostas
*  Entrada e saída de dados (*Input/Output*)

#### 2. Operações com Números Inteiros ('números_inteiros.html')
  * **Descrição:** Atividade focada no ensino e prática de conceitos e operações com números inteiros.
  *  **Conceitos de Programação:**
  *  Estruturas condicionais ('se...senão')
  *  Operadores matemáticos e comparação lógica
-----
## 🛠️ Tecnologias e Ferramentas
* **Scratch 3.0** (Mit Media Lab)
*  **TurboWarp Packager** (Conversão para HTML5)
*  **GitHub Pages** (Hospedagem Web)
